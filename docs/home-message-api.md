# 관리자 메인 메시지 API

전체 사용자에게 보여줄 공통 문구 하나를 DB에 저장합니다. 관리자 JWT가 필요합니다.

## 조회

`GET /api/admin/home-message`

응답: `200 OK`, `{"message":"오늘도 좋은 하루 보내세요!"}`

미설정 상태는 `{"message":""}`입니다.

## 설정 및 해제

`PUT /api/admin/home-message`

```json
{"message":"오늘도 좋은 하루 보내세요!"}
```

- 최초 설정과 기존 문구 교체 모두 같은 API를 사용합니다.
- 저장 후 `200 OK`와 저장된 `{"message":"..."}`를 반환합니다.
- `message`는 필수 문자열이며 원본 입력 기준 최대 500자입니다.
- 앞뒤 공백은 제거하고 내부 줄바꿈은 유지합니다.
- `{"message":""}` 또는 공백만 입력하면 문구를 해제합니다.
- 누락, null, 500자 초과는 `400`, 비로그인은 `401`, 일반 사용자는 `403`입니다.
- 로그인 여부와 관계없이 `GET /api/home`의 최상위 `message`에 저장된 문구가 반환됩니다.
- 프론트엔드는 문구를 일반 텍스트로 표시하고 빈 문자열이면 메시지 영역을 숨기면 됩니다.

## DB 적용

기존 DB에는 배포 전에 `docs/home-message-migration-mysql.sql`을 실행해야 합니다.
신규 스키마에는 `docs/database-schema-mysql.sql`의 `home_messages` 테이블이 포함됩니다.
애플리케이션은 고정 ID 1을 사용하며 미설정 상태에서는 행 없이도 빈 문자열을 반환합니다.
